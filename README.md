# Portfolio: Mohammed Khadeir (Simo)

Bilingual (English/French) portfolio. A plain static site: no build step.

- `index.html` is the whole page. Edit it directly.
- Screenshots are in `img/`.
- Add `#fr` to the link to open the French version.
- Contact goes through Fiverr (no phone or email on the page, to respect Fiverr's rules).
  Update the `fiverr-link` button with your Fiverr profile URL.

Published with GitHub Pages (Settings → Pages → Deploy from branch: main, / root). Paths are relative so it also works on Vercel or Netlify.
